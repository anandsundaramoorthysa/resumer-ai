## Shell quirk (this machine)

The repo path contains `&` (`D:\Hackathon & Companies\resumer-ai`), which breaks npm's script
shims: `npm run typecheck` fails with `'Companies\resumer-ai\node_modules\.bin\' is not
recognized`. Call the tool through node instead:

```bash
node node_modules/typescript/bin/tsc --noEmit                       # + -p scripts/tsconfig.json
node node_modules/eslint/bin/eslint.js                              # lint
node node_modules/tsx/dist/cli.mjs --tsconfig scripts/tsconfig.json tests/run.mts
TEST_FILTER=db- ...                                                 # only the PGlite suites
```
